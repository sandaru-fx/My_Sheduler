# TimeFlow Scheduler ⏳

A premium, immersive productivity application built with React, Three.js, and Node.js.

The project is organized into a monorepo-style MVC architecture:


## 🚀 Getting Started

### 1. Installation

Install dependencies for both frontend and backend:

```bash
npm run install:all
```

### 2. Running the Application

Start both frontend and backend servers concurrently:

```bash
npm run dev
```

- **Frontend**: http://localhost:5173
- **Backend**: http://localhost:5000

## 🛠️ Tech Stack

- **Frontend**: React, TypeScript, Vite, Tailwind CSS, Three.js (R3F)
- **Backend**: Node.js, Express, MongoDB, Mongoose
- **Architecture**: MVC (Model-View-Controller)
